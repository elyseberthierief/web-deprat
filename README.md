# web-deprat
Import de la sauvegarde WordPress DEPRAT du 14 novembre 2026.

- `wp-content/code-snippets/` contient les extraits PHP tels qu'enregistrés dans Code Snippets. Les fichiers texte ne sont pas exécutables par WordPress.
- `wp-content/uploads/custom-css-js/` contient les feuilles de style personnalisées retrouvées.
- `structure/` contient les inventaires des pages et modèles publiés, des menus, des catégories, des snippets et des dépendances.

Les inventaires décrivent la structure du site. Pour restaurer le site complet, utiliser la sauvegarde Duplicator conservée séparément.
